# CSE 210: Programming with Classes

This repository contains my C# coursework and projects focused on object-oriented programming. The work progresses from foundational syntax into encapsulation, abstraction, inheritance, polymorphism, class design, and multi-object application structure.

## Selected projects

### Eternal Quest Goal Tracker

A goal-management console application built with a class hierarchy for simple, eternal, and checklist goals. The project applies inheritance, polymorphism, persistence, and user-driven state changes.

### Exercise Tracking

An activity model for running, cycling, and swimming. Shared behavior is defined through a base activity class, while each activity calculates distance, speed, pace, and summaries through specialized implementations.

### Mindfulness Activities

A structured console application for breathing, reflection, and listing exercises. It uses shared activity behavior, timing, prompts, and reusable components.

### Online Ordering

An ordering model composed of products, customers, addresses, and orders. It calculates totals, shipping costs, labels, and packing information through collaborating classes.

### Scripture Memorizer

A word-hiding memorization tool built from scripture, reference, and word objects. It tracks visibility state and progressively changes the rendered passage.

## Topics demonstrated

- C# and .NET console applications
- Classes and object composition
- Encapsulation and state management
- Inheritance and polymorphism
- Abstract classes and method overriding
- Collections, loops, validation, and file operations
- Breaking larger problems into focused responsibilities

## Repository organization

Projects are organized by course week. Each project includes its own `.csproj` file and can be run from that project directory:

```bash
dotnet run
```

This repository represents coursework completed while building my independent C# foundation.
